# Dark-photon DM literature inputs for the wire-grid ENZ haloscope Letter (0.25–8 meV)

Compiled 2026-10-19. Every entry gives value · source (arXiv id, eq./fig./table, PDF page) · flag.
Flags: **[V]** = read directly in the primary paper's full text. **[V-dig]** = digitised by me from the figure's vector paths in the primary PDF (calibrated on tick-line coordinates; expect ±0.03–0.05 dex). **[D]** = derived/cross-checked by me, *not* stated in the paper. **[U]** = unverified.
PDF page = page index of the arXiv PDF that was fetched (version given).

**Scope and deviations, stated up front**
- AxionLimits files were fetched from `raw.githubusercontent.com/cajohare/AxionLimits/master/limit_data/DarkPhoton/` (repo HEAD 7d375f48, 2026-01-27). The CSV keeps only rows with 1e-4 ≤ m ≤ 2e-2 eV, as requested.
- The 2024–2026 search for new direct DP-DM searches between 60 GHz and 2 THz used targeted web/arXiv queries. It is **not exhaustive**, so read "no other result" as provisional.
- BREAD, SQWARE and ALPHA numbers read off figures are digitisations (flag [V-dig]), not tabulated values.
